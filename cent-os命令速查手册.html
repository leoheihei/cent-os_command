02查看操作系统版本

注意：操作系统版本（发行版）和内核版本（Kernel）不是一回事。

目的命令
标准 OS 信息（推荐）cat /etc/os-release
CentOS 版本cat /etc/centos-release
RHEL 系版本cat /etc/redhat-release
发行版信息cat /etc/system-release
详细信息（OS + 内核 + 架构）hostnamectl
LSB 信息（需装 redhat-lsb-core）lsb_release -a
CentOS 版本包rpm -q centos-release
主版本号rpm -E %{rhel}
内核版本uname -r
完整内核信息uname -a
系统架构uname -m
32 / 64 位getconf LONG_BIT

输出示例

$ cat /etc/os-release
NAME="CentOS Linux"
VERSION="7 (Core)"
ID="centos"
ID_LIKE="rhel fedora"
VERSION_ID="7"
PRETTY_NAME="CentOS Linux 7 (Core)"
CPE_NAME="cpe:/o:centos:centos:7"
HOME_URL="https://www.centos.org/"

$ hostnamectl
   Static hostname: web01
         Icon name: computer-vm
           Chassis: vm
    Virtualization: kvm
  Operating System: CentOS Linux 7 (Core)
       CPE OS Name: cpe:/o:centos:centos:7
            Kernel: Linux 3.10.0-1160.el7.x86_64

内核版本中的 el7 / el8 / el9 表示对应的 RHEL / CentOS 大版本系列，例如 3.10.0-1160.el7.x86_64 属于 CentOS 7 系列。
最小化安装可能没有 lsb_release，需先 yum install redhat-lsb-core 或 dnf install redhat-lsb-core。

03目录操作 cd

cd 是 Shell 内建命令（change directory），只影响当前 Shell 会话。查看帮助：help cd。

语法与选项

cd [选项] [目录]
选项说明
-L逻辑路径模式（默认），跟随符号链接
-P物理路径模式，解析符号链接使用真实路径
-e与 -P 同用时，无法确定当前目录则返回非零状态
--结束选项，用于目录名以 - 开头的情况

常用操作

命令作用
cd回到当前用户家目录
cd ~回到当前用户家目录
cd /进入根目录
cd /etc按绝对路径进入
cd etc按相对路径进入当前目录下的 etc
cd ..进入上一级目录
cd ../..进入上两级目录
cd .进入当前目录（通常无变化）
cd -返回上一次所在目录并打印该目录
cd ~user进入指定用户的家目录
cd "My Documents"目录名含空格需加引号
cd -- -dir进入以 - 开头的目录
cd -P /tmp/link以物理真实路径进入符号链接目录

特殊路径符号

符号含义
/根目录
.当前目录
..父目录
~当前用户家目录
~user指定用户家目录
-上一次工作目录（仅 cd 特殊识别，依赖 OLDPWD）

带空格与变量

cd "My Documents"      # 双引号
cd 'My Documents'      # 单引号
cd My\ Documents       # 反斜杠转义

dir="/var/www/my site"
cd "$dir"              # 变量必须加引号，否则空格会被拆成多个参数

CDPATH 快速跳转

export CDPATH=.:~:/var/www:/opt
cd html        # 当前目录没有 html 时，会自动尝试 /var/www/html 等
脚本中不建议依赖 CDPATH，它可能导致 cd 跳到意外位置。脚本开头常写 unset CDPATH。

目录栈：pushd / popd / dirs

命令作用
pushd 目录进入目录并压入栈
popd弹出栈顶，返回新栈顶目录
dirs显示目录栈
dirs -v带编号显示目录栈（编号 0 为当前目录）
dirs -c清空目录栈
pushd +N旋转到栈中第 N 个目录
popd +N删除栈中第 N 个目录

常见错误

错误提示原因
No such file or directory目录不存在或路径拼错
Not a directory目标是文件而非目录
Permission denied路径中某一级目录缺少执行权限 x
too many arguments路径含空格但未加引号
OLDPWD not set尚未切换过目录就使用 cd -
sudo: cd: command not found不能用 sudo cd，见下方说明
为什么 sudo cd /root 无效？ cd 是 Shell 内建命令，sudo 会启动新进程，切换只发生在该子进程中，不会影响当前 Shell。正确做法：sudo -i 或 sudo bash 后再 cd。

04ls 命令速查表

语法：ls [选项] [文件或目录...]。CentOS 默认使用 GNU ls，支持 --color、--time-style、--group-directories-first 等扩展选项。

最常用

命令作用
ls列出当前目录非隐藏文件
ls -l长格式显示
ls -lh长格式 + 人类可读大小
ls -lah长格式 + 人类可读 + 含隐藏文件
ls -a显示所有文件，含 . 和 ..
ls -A显示隐藏文件，但不含 . 和 ..
ls -lt按修改时间排序，新到旧
ls -ltr按修改时间排序，旧到新
ls -lS按文件大小排序，大到小
ls -lSh按人类可读大小排序
ls -R递归列出子目录
ls -d */只列出当前目录下的子目录
ls -ld /path查看目录本身，不展开内容
ls -i显示 inode 号
ls -Z显示 SELinux 安全上下文
ls -F给目录、可执行文件等加类型标记
ls -1每行一个文件
ls --color=auto彩色输出

显示与信息类选项

选项说明
-l长格式
-h人类可读大小，如 1K、234M
--si使用 1000 进制，如 kB、MB
-s显示占用的块数
-i显示 inode
-n显示数字 UID / GID
-Z显示 SELinux 上下文
-g类似 -l，但不显示所有者
-o类似 -l，但不显示所属组
-G长格式中不显示组
--full-time显示完整时间
--time-style=long-iso时间格式：long-iso / iso / full-iso / +%F %T
-I '*.log'忽略匹配模式的文件
-B忽略备份文件（*~）

排序与时间

选项说明
-t按修改时间排序
-S按文件大小排序
-X按扩展名排序
-r反转排序
-U不排序，按目录顺序
-v自然排序，file2 排在 file10 前
-u配合 -lt 使用访问时间 atime
-c配合 -lt 使用状态改变时间 ctime
--group-directories-first目录排在文件前面

输出格式

选项说明
-1单列输出
-C多列纵向输出（默认）
-x多列横向输出
-m逗号分隔输出
-F类型标记：/ 目录、* 可执行、@ 链接
-p只给目录加 /
-Q文件名加双引号
-b转义非图形字符
-L跟随符号链接显示目标信息
-H只跟随命令行上的符号链接

-l 长格式字段

-rw-r--r-- 1 root root 1234 Sep 26 12:00 file.txt
lrwxrwxrwx 1 root root    7 Sep 26 12:00 link -> /etc/hosts
字段含义
-rw-r--r--文件类型 + 权限
1硬链接数
root所有者
root所属组
1234大小（默认字节）
Sep 26 12:00修改时间
file.txt文件名

文件类型首字符：- 普通文件、d 目录、l 符号链接、c 字符设备、b 块设备、s 套接字、p 命名管道。

常见组合

ls -lah
ls -ltr
ls -lSh
ls -lh --time-style=long-iso
ls -l --group-directories-first
ls -d */
ls -ld /var/log
ls -i /etc/hosts
ls -Z /var/www
ls -l /etc/yum.repos.d/*.repo
ls -lt | head          # 查看最新的几个文件
注意：ls -l 中的 total 是块数而非字节数；查看目录本身用 ls -ld 目录； 脚本中不要解析 ls 输出，应使用 find、stat、readlink。

19脚本中的常见实践

安全切换目录

cd -- "$dir" || exit 1
cd -- "$dir" || { echo "无法进入 $dir"; exit 1; }

子 Shell 中临时切换

(cd /var/log && ls)     # 不影响当前 Shell 的工作目录

脚本头部模板

#!/bin/bash
set -e
unset CDPATH

cd -- "$1" || exit 1
pwd
常用 set -e（出错即退出）、set -u（使用未定义变量报错）、 set -o pipefail（管道任一环节失败即失败）提升脚本健壮性。
